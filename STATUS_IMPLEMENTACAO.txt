🔄 FLUXO DE FUNCIONAMENTO
═══════════════════════════════════════════════════════════════════════════

CRIAR PRODUTO:
┌─────────────────────────────────────────────────────────────┐
│ 1. User clica "Novo Produto"                               │
│    └─ ProductModal abre                                    │
│                                                             │
│ 2. User preenche dados:                                    │
│    ├─ name (obrigatório)                                  │
│    ├─ categoryId (obrigatório)                            │
│    ├─ price (obrigatório)                                 │
│    └─ description (opcional)                              │
│                                                             │
│ 3. User faz upload de imagem                              │
│    ├─ ImageUpload valida (tipo, tamanho)                │
│    ├─ Exibe preview                                       │
│    ├─ Upload para /api/v1/uploads/image?folder=products │
│    └─ Retorna { url, publicId }                          │
│                                                             │
│ 4. User clica "Salvar Produto"                            │
│    ├─ ProductModal envia POST /api/v1/products           │
│    ├─ Body: { name, categoryId, price, image, ... }      │
│    ├─ API cria produto com imagem                        │
│    ├─ updateProduct (contexto local)                      │
│    └─ Modal fecha, produto aparece na lista              │
└─────────────────────────────────────────────────────────────┘

EDITAR CATEGORIA:
┌─────────────────────────────────────────────────────────────┐
│ 1. User clica "Editar" em categoria                        │
│    └─ CategoryModal abre com dados existentes             │
│                                                             │
│ 2. User modifica dados e/ou imagem                        │
│    ├─ Se nova imagem: upload para Cloudinary             │
│    └─ Preview atualizado                                  │
│                                                             │
│ 3. User clica "Salvar Categoria"                          │
│    ├─ Envia PATCH /api/v1/categories/:id                 │
│    ├─ Body: { name, image, description, order }          │
│    ├─ API:                                                │
│    │  ├─ Deleta imagem antiga do Cloudinary             │
│    │  ├─ Salva nova imagem                              │
│    │  └─ Atualiza categoria                             │
│    ├─ updateCategory (contexto local)                    │
│    └─ Modal fecha, categoria atualizada                 │
└─────────────────────────────────────────────────────────────┘

CONFIGURAR RESTAURANTE:
┌─────────────────────────────────────────────────────────────┐
│ 1. User vai para /settings                                 │
│    └─ Aba "Restaurante" com RestaurantSettings           │
│                                                             │
│ 2. User preenche dados básicos                            │
│    ├─ name, email, phone, website, description           │
│    ├─ address, city, state, zipCode                      │
│    └─ Validações em tempo real                           │
│                                                             │
│ 3. User faz upload de logo                                │
│    ├─ ImageUpload (folder: logos)                        │
│    ├─ Preview da logo                                     │
│    └─ URL salva em state                                  │
│                                                             │
│ 4. User faz upload de cover                               │
│    ├─ ImageUpload (folder: covers)                       │
│    ├─ Preview do cover                                    │
│    └─ URL salva em state                                  │
│                                                             │
│ 5. User clica "Salvar Configurações"                      │
│    ├─ Envia PATCH /api/v1/settings/restaurant            │
│    ├─ Body: { name, phone, email, logo, coverImage, ... }│
│    ├─ API:                                                │
│    │  ├─ Deleta imagens antigas                         │
│    │  ├─ Salva novas imagens                            │
│    │  └─ Atualiza restaurante                           │
│    ├─ onSave() callback dispara                          │
│    └─ Mensagem de sucesso                                │
└─────────────────────────────────────────────────────────────┘
