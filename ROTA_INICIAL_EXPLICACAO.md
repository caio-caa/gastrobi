# Como Funciona a Rota Inicial

Olha só como é bem simples. O cliente abre o aplicativo e vai direto para uma página que pede para escanear um código QR. Ele aponta a câmera do celular para o QR code que recebeu, o código é lido automaticamente e ele é redirecionado para o cardápio do restaurante. É literalmente isso. Nada de lista de restaurantes, nada de busca complicada. O cliente escaneia o QR que mandamos para ele, vê o cardápio, faz o pedido e pronto. Se ele quiser fazer outro pedido em outro restaurante depois, volta para a página inicial e escaneia outro QR code. Simples assim.

O sistema valida se o restaurante existe quando lê o QR, se tiver algum problema mostra uma mensagem de erro e o cliente tenta novamente. Tudo acontece no app de forma bem fluida e rápida. Cada restaurante tem seu próprio QR code, pode mandar por WhatsApp, imprimir no cardápio, colocar na mesa, no talão, em qualquer lugar. O cliente aponta e pronto, vai direto pro cardápio desse restaurante.

Depois que o cliente escolhe os produtos, adiciona ao carrinho e confirma o pedido, ele recebe a opção de fazer um novo pedido ou voltar. Se ele voltar, volta para a tela inicial e pode escanear outro QR code de outro restaurante. Não mistura pedido de um restaurante com outro, cada um é independente.

E o legal é que essa página inicial é customizável com as cores e logo de cada marca. Então mesmo que seja a mesma página para todos, cada cliente (restaurante) vê com sua própria identidade visual.
